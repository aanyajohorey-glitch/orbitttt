# 3-minute demo script

**Before the viva:** open the app once to warm it up (the first start is slow). Turn on **offline demo
mode** (About -> Settings) if the internet is unreliable. Have one test idea ready to paste.

| Time | Do | Say |
|---|---|---|
| 0:00 | Open ORBIT; the Feel / Create choice appears. Click **Create**. | "ORBIT is a companion for creative people: it helps you feel okay and helps you make things." |
| 0:15 | Type: *a short film about a rainy Sunday café in Mumbai, nostalgic and warm*. Click **Build my universe** (skip the quick questions). | "Watch the universe form: one Vibe Vector drives everything." |
| 0:35 | Point at the orbit view, then the app colours changing. Scroll: concept, palette with contrast checks, fonts, moodboard, aesthetics, music, creators. | "Palette from a colour-wheel rule, fonts from a tagged list, music and creators ranked by cosine similarity with a diversity step. Nothing is scraped." |
| 1:05 | Click **Warmer**, then **Use Weird**. | "Refining changes the vector, so everything updates together. Three directions: safe, bold, weird." |
| 1:25 | In *How's the project going?* type **I'm stuck and it has to be perfect**, then click **Tell ORBIT**. | "The bridge to wellbeing: it spots a creative block and offers a break." |
| 1:40 | Choose the **Perfectionism exercise** or the game, then **Back to my project**. | "And back to exactly where I was." |
| 1:55 | Expand **How this was made**, then download the **Creative brief (PDF)**. | "Every number is visible; the brief is ready to share." |
| 2:15 | Go to **Feel**, type a crisis phrase from `safety_tests.csv` (for example *"I don't want to live anymore"*). | "Safety always comes first: a fixed response with Tele-MANAS 14416 and 112. No AI, no games, nothing stored." |
| 2:40 | Open **About -> AI Lab** for a moment. | "And this is how I measured it, including where it fails: crisis recall on new phrasings is still low, so helplines are always visible." |
| 3:00 | End. | |

**If something fails:** demo mode keeps sample sentences working offline; Panic wipe resets everything
in one click.
